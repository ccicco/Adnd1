The R879 registry schema - the maintenance-arc opener, the
FINAL post-DDG schema every def of every book normalizes
to. The base MM1 field order (40 keys, mm2lua.py), the
eight schema-adjustment keys the promotion seams added
(saveAs, saveAsBonus, loadNormal, loadMax, rank, plane,
transform, wsgRoles), and the nine DDG keys the deity
promotion feeds (divineRank, worshippersAlignment, symbol,
areaOfControl, classLevelsRaw, classLevelsCooked,
hitPointsRaw, hitPoints, hitPointsNote).

The sentinel doctrine: full-field emission fills every key
the book does not print - "n/a" for strings, -1 for ints -
both distinct from every real print value (the printed
"Nil" and "None" are REAL values and stay). The audits
read the sentinels exactly, so fail-on-wrong stays honest.
