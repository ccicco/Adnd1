# WSG Gap Report - the book vs the repo

R425 ARC OPENER. The wilderness arc names the Wilderness Survival Guide. This report inventories the whole WSG book against the engine and is, by design, lossless: it mirrors the book own structure (the 14 chapters, the DM section, the weather appendix, the compiled tables), every named table from the book own Tables index gets its own line item (the manifest - nothing can be skipped silently), and every load-bearing prose mechanic is its own sub-item rather than a clause in a paragraph. Engine scope unchanged: the data-driven registries (append a row, not a re-carve), the rules/ pin headers, the battery audits. Closure criterion: a box closes when the feature PLAYS right - compiling is not the test; a round closes an item by flipping the box in the SAME commit. The universe: this book, the landed DMG, PHB and UA reports, and the engine pins they carry; the engine ingests any source the same way (survey, gap report, pins, provenance).

Conventions as the UA report: [x] verified against the book text (with the round); [~] verified DIVERGENT; [ ] open item; DEFERRED for wants gated on an engine layer not yet built. Page cites are the PRINTED book pages (the pdf page = printed + 1; the Table 1/2 grids live on printed p. 12).
