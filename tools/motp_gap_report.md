# MotP Gap Report - the book vs the repo

MOTP ARC OPENER, ROUND ZERO. The planar arc names the Manual
of the Planes (1987, Jeff Grubb, 128 pp.). This report
inventories the whole MotP book against the engine and is, by
design, lossless: it mirrors the book's own structure (the
introduction, the Ethereal, the inner planes, the Astral, the
outer planes, the appendices, the indices), every named plane
and section from the book's own table of contents gets its own
line item (the manifest - nothing can be skipped silently), and
every load-bearing prose mechanic is its own sub-item rather
than a clause in a paragraph. Engine scope unchanged: the
rules/ pin headers, the battery audits, the census. Closure
criterion: a box closes when the feature PLAYS right -
compiling is not the test; a round closes an item by flipping
the box in the SAME commit.

Conventions as the DSG report: [x] verified against the book
text (with the round); [~] verified DIVERGENT; [ ] open item.
Page cites are the PRINTED book pages from the book's own table
of contents; the pdf-page offset (printed + 1 for this scan)
gets pinned at the extraction round R564.

CROSS-BOOK SEAM WARNING (standing rule for this arc): the MotP
references the DSG and WSG material already pinned (the
underdark theories, the Plane of Earth doors, the elemental
wider context), and the MotP outer-plane pantheon material is
the upstream source of the Legends and Lore lore. NOTHING is
auto-credited. An MotP box may only close on pins that carry
the MotP's own text.

OCR NOTE (standing for this arc): the spell-summary tables on
printed pp. 8-9 are badly garbled in the capture OCR; that box
closes only against a careful column-by-column reconstruction.
